Complete block reference (8 blocks)

Document Data

Parse HTML and Markdown into target-local named document trees, edit text, and expose deterministic UTF-8 HTTP response bodies.

Blocks

Use parse HTML ... as document ... or parse Markdown ... as document ..., then inspect, replace, or serialize its text. Tree locations use $ or numeric paths such as $[0][1]. HTML also supports one simple tag, #id, or .class selector.

Safety boundary

Parsing does not sanitize HTML, execute scripts, or mount a DOM. HTML/Markdown conversion is rejected because it may be lossy. The extension is unsandboxed and its DOCUMENT_DATA_MVP flag defaults to off.

Development

Run pnpm run check. See the repository README and architecture documents for limits and the Named Data provider contract.
